# FRONTEND README

## Description

This frontend was developed using:
- Node.js
- Express.js
- EJS
- Axios

## Features

1. Home Page
2. Assignment 1 Page
3. Assignment 2 Page
4. Combined Assignments Page

## Communication

The frontend communicates with:
- Backend-One for Excel operations
- Backend-Two for email sending

## How To Run

1. Open terminal
2. Run:

npm install

3. Start server:

node server.js

4. Open browser:

http://localhost:3000
